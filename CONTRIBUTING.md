# Contributing

Thank you for contributing to Awesome Vector Tools!

## Guidelines

- Search existing entries before adding a new one to avoid duplicates.
- Add new entries in the appropriate category, in alphabetical order (within the category).
- Use the format: `[Tool Name](https://url) — Short description.`
- The description should be concise (one sentence) and explain what the tool does.
- Only add tools that are actively maintained and publicly accessible.
- Open-source tools should link to their GitHub/GitLab repo.
- Commercial tools should link to their homepage.

## Pull Request Process

1. Fork the repository.
2. Add your tool to the appropriate section in `README.md`.
3. Submit a pull request with a brief description of the tool.

## Quality Standards

- Tools must be relevant to SVG, vector graphics, or image-to-vector conversion.
- No spam, affiliate links, or low-quality tools.
- Preference for tools with active communities or recent updates.
