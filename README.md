## Image to Vector Conversion

- **[VectoSolve](https://vectosolve.com)** — AI-powered image to SVG converter with 8 style modes (standard, HD, Cricut, laser, embroidery, stencil, coloring, stamp). API, SDK, MCP server, browser extensions, and 29K+ free SVG marketplace.
- [Potrace](http://potrace.sourceforge.net/) — Open-source bitmap tracing engine. CLI tool that converts bitmaps to scalable vector graphics. Powers many other tools.
- [AutoTrace](https://github.com/autotrace/autotrace) — Open-source bitmap to vector converter. Supports multiple output formats.
- [SVGcode](https://svgco.de/) — Browser-based PWA that converts raster images to SVG using the Potrace algorithm. Free and open-source.
- [Vector Magic](https://vectormagic.com/) — Desktop and online vectorizer with automatic and manual tracing modes.
- [Adobe Illustrator Image Trace](https://www.adobe.com/products/illustrator.html) — Built-in tracing feature in Adobe Illustrator for converting raster to vector.
- [Inkscape Trace Bitmap](https://inkscape.org/) — Free vector editor with built-in Potrace-based bitmap tracing.
- [Vectorizer.ai](https://vectorizer.ai/) — AI-powered vectorization service with detailed output.
- [SVGMaker.io](https://svgmaker.io/) — Online SVG converter and editor with drawing tools.

## SVG Editors

- **[VectoSolve SVG Studio](https://vectosolve.com/svg-studio)** — Free browser-based SVG editor with path/point editing, layers, shapes, and integrated AI vectorization.
- [Inkscape](https://inkscape.org/) — Free, open-source vector editor. Full-featured alternative to Illustrator.
- [SVG-Edit](https://github.com/nicholasgasior/SVG-Edit) — Web-based SVG editor. Embeddable, open-source.
- [Boxy SVG](https://boxy-svg.com/) — Modern SVG editor for the web and desktop.
- [Vecta.io](https://vecta.io/) — Online SVG editor with real-time collaboration.
- [Method Draw](https://editor.method.ac/) — Simple, clean SVG editor in the browser.
- [SVGator](https://www.svgator.com/) — SVG animation and editing tool.

## SVG Optimization

- [SVGO](https://github.com/svg/svgo) — Node.js-based tool for optimizing SVG files. The industry standard.
- [svgo-online](https://jakearchibald.github.io/svgomg/) — Web UI for SVGO (SVGOMG).
- [SVG Cleaner](https://github.com/nicholasgasior/svgcleaner) — CLI tool that removes unnecessary data from SVGs.
- [Nano SVG](https://vecta.io/nano) — Online SVG compressor with smart optimization.
- [SVG Optimizer by Peter Collingridge](https://petercollingridge.appspot.com/svg-optimiser) — Browser-based SVG optimization.

## SVG Libraries

### JavaScript/TypeScript
- [Snap.svg](http://snapsvg.io/) — JavaScript library for working with SVGs. By the creator of Raphael.
- [SVG.js](https://svgjs.dev/) — Lightweight library for manipulating and animating SVG.
- [D3.js](https://d3js.org/) — Data-driven document manipulation, heavily used for SVG-based visualizations.
- [Paper.js](http://paperjs.org/) — Vector graphics scripting framework on top of HTML5 Canvas.
- [Fabric.js](http://fabricjs.com/) — Canvas library with SVG-to-canvas and canvas-to-SVG capabilities.
- [Two.js](https://two.js.org/) — 2D drawing API that renders to SVG, Canvas, and WebGL.
- [Rough.js](https://roughjs.com/) — Creates hand-drawn, sketchy SVG graphics.

### Python
- [svgwrite](https://github.com/mozman/svgwrite) — Python library to create SVG drawings.
- [CairoSVG](https://cairosvg.org/) — Convert SVGs to PDF, PNG, and PS with Python.
- [drawsvg](https://github.com/cduck/drawsvg) — Programmatically generate SVG images in Python.

### Rust
- [resvg](https://github.com/RazrFalcon/resvg) — High-quality SVG rendering library in Rust.
- [usvg](https://github.com/nicholasgasior/usvg) — SVG simplification library (part of resvg).

## SVG Animation

- [GreenSock (GSAP)](https://greensock.com/) — Professional-grade animation library with SVG support.
- [Lottie](https://airbnb.io/lottie/) — Parse After Effects animations exported as JSON and render as SVG.
- [anime.js](https://animejs.com/) — Lightweight animation library with SVG path animation support.
- [Vivus](https://maxwellito.github.io/vivus/) — JavaScript library for SVG stroke drawing animation.
- [Framer Motion](https://www.framer.com/motion/) — React animation library with SVG support.

## Format Conversion

- **[VectoSolve Format Converter](https://vectosolve.com/convert/svg-to-dxf)** — Convert SVG to DXF, G-code, embroidery formats (PES, DST, JEF), and more.
- [CloudConvert](https://cloudconvert.com/) — Online file converter supporting 200+ formats including SVG.
- [Convertio](https://convertio.co/) — Online converter for vector and raster formats.
- [svg2dxf](https://github.com/nicholasgasior/svg2dxf) — Command-line SVG to DXF converter.
- [Embroidermodder](https://www.embroidermodder.org/) — Open-source machine embroidery editor and converter.
